# 📸 Photography Website

A modern and responsive Photography Website built using HTML and CSS.  
This project showcases photography portfolios, galleries, and creative visual content with an attractive user interface and clean design.

---

# 🚀 Features

- Responsive website design
- Modern photography portfolio layout
- Image gallery section
- Hero banner section
- About section
- Contact section
- Smooth navigation
- Mobile-friendly interface
- Clean and minimal UI

---

# 🛠️ Tech Stack

## Frontend
- HTML5
- CSS3
